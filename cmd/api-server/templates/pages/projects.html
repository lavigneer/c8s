Webhook Setup Instructions

GitHub Setup

  1. Go to your repository Settings
  2. Click "Webhooks" in the sidebar
  3. Click "Add webhook"
  4. Paste the webhook URL above in the "Payload URL" field
  5. Select "Push events" and "Pull request events"
  6. Click "Add webhook"

Tip: The webhook will automatically trigger pipelines when you push to any branch or open a pull request.
