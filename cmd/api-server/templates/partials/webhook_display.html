Setup Instructions

{{if eq .GitPlatform "github"}}
  1. Go to your repository on GitHub
  2. Click Settings in the repository menu
  3. Select Webhooks from the left sidebar
  4. Click Add webhook
  5. Paste the webhook URL above in the Payload URL field
  6. Set Content type to application/json
  7. Under Which events would you like to trigger this webhook?:
    • Select Push events
    • Select Pull request events
  8. Click Add webhook
{{else if eq .GitPlatform "gitlab"}}
  1. Go to your project on GitLab
  2. Click Settings → Webhooks
  3. Paste the webhook URL above in the URL field
  4. Under Trigger, select:
    • Push events
    • Merge request events
  5. Click Add webhook
{{else}}
  1. Configure your git hosting platform to send webhooks to this URL
  2. Set the webhook to trigger on push and pull request events
  3. Ensure the webhook content type is set to JSON
{{end}}

💡 Tip: Once configured, the webhook will automatically trigger C8S pipelines whenever you push code or open a pull request.

{{end}}
