# Tilt Development Setup Guide

Quick guide for setting up C8S development with Tilt and automatic webhook TLS certificates.

## Prerequisites

- Docker
- Kubernetes cluster (k3s, kind, Docker Desktop, etc.)
- Helm 3.x
- Tilt

## Quick Start (Recommended)

```bash
# 1. Start Tilt - this automatically:
#    - Updates Helm dependencies (installs cert-manager)
#    - Builds Docker images for all components
#    - Deploys C8S with webhook TLS certificates
tilt up

# 2. Wait for all services to be ready (watch Tilt UI on http://localhost:10350)

# 3. Access the dashboard (after deployment completes)
kubectl port-forward svc/c8s-frontend -n c8s-system 3000:80
# Visit http://localhost:3000
```

## What Gets Deployed

When you run `tilt up`, the following happens automatically:

1. **Helm Dependencies**
   - cert-manager v1.13.0 is installed in cert-manager namespace
   - All cert-manager CRDs are registered
   - cainjector webhook is configured

2. **C8S Stack**
   - API Server (port 8080)
   - Controller (watches pipelines)
   - Webhook (with auto-generated TLS certificates)
   - Frontend (port 3000 via NodePort)

3. **Certificates**
   - Self-signed CA generated by cert-manager
   - Webhook TLS certificate auto-provisioned
   - ValidatingWebhookConfiguration auto-injected with caBundle

## How It Works

### Automatic Helm Dependencies

The `Tiltfile` includes a `helm-dependencies` resource that runs:
```bash
helm dependency update ./chart/c8s
```

This:
- Reads Chart.yaml dependencies
- Downloads cert-manager chart from https://charts.jetstack.io
- Creates a Chart.lock file
- Makes dependencies available for Helm deployment

### Cert-Manager Integration

The C8S Helm chart is configured with:
```yaml
certManager:
  enabled: true
  installDependency: true
  issuerType: self-signed
```

This causes the chart to:
1. Install cert-manager as a Helm subchart
2. Create a self-signed Issuer in c8s-system namespace
3. Request a Certificate from the Issuer
4. Automatically inject caBundle into ValidatingWebhookConfiguration

### Webhook TLS

The webhook deployment:
- Mounts certificate from Secret `c8s-webhook-tls`
- Listens on port 8443 with TLS
- Certificate auto-renewed 30 days before expiry

## Tilt Workflow

### Triggering Helm Dependency Updates

If you modify Chart.yaml dependencies:
```bash
# In Tilt UI: Click "▶ Trigger" next to "helm-dependencies"
# Or in terminal: tilt trigger helm-dependencies
```

### Viewing Logs

```bash
# C8S deployment logs
tilt logs c8s

# Specific component logs
tilt logs api-server
tilt logs controller
tilt logs webhook
tilt logs frontend

# Cert-manager logs
kubectl logs -n cert-manager -l app=cert-manager
```

### Stopping Tilt

```bash
# Stop Tilt and remove resources
tilt down

# View Tilt dashboard
tilt up && open http://localhost:10350
```

## Configuration

### Development Values Override

The `tilt/c8s-values.yaml` file overrides default values:
- `certManager.enabled: true` - Enable cert-manager integration
- `certManager.installDependency: true` - Auto-install cert-manager
- `components.webhook.enabled: true` - Enable webhook with TLS
- `storage.type: local` - Use local storage instead of S3

### Customizing Setup

To modify the Tilt setup, edit:

1. **Tiltfile** - Tilt deployment configuration
   - Docker build settings
   - Helm resource configuration
   - File watchers
   - Local resources

2. **tilt/c8s-values.yaml** - C8S values for Tilt
   - Component replica counts
   - Image registries
   - Storage type
   - Cert-manager settings

3. **chart/c8s/values-dev.yaml** - Development defaults
   - Resource requests/limits
   - Log levels
   - Probe configuration

## Troubleshooting

### Helm Dependency Update Fails

```bash
# Manually update dependencies
helm repo add jetstack https://charts.jetstack.io
helm repo update
helm dependency update ./chart/c8s
```

### Certificate Not Generated

```bash
# Check cert-manager is running
kubectl get pods -n cert-manager

# Check certificate status
kubectl describe certificate c8s-webhook-tls -n c8s-system

# Check cert-manager logs
kubectl logs -n cert-manager -l app=cert-manager | grep c8s
```

### Webhook Pod Failing

```bash
# Check webhook deployment
kubectl describe deployment c8s-webhook -n c8s-system

# Check if certificate Secret exists
kubectl get secret c8s-webhook-tls -n c8s-system

# Check webhook pod logs
kubectl logs -n c8s-system -l app.kubernetes.io/component=webhook
```

### caBundle Not Injected

```bash
# Verify cert-manager cainjector is running
kubectl get pods -n cert-manager -l app=cainjector

# Check ValidatingWebhookConfiguration annotation
kubectl get validatingwebhookconfigurations c8s-validating-webhook -o yaml | grep cert-manager

# Wait for cainjector to inject (usually < 10 seconds)
kubectl get validatingwebhookconfigurations c8s-validating-webhook -o yaml | grep caBundle
```

## Performance Notes

- **First Deploy**: Takes ~2-3 minutes (builds images, installs cert-manager)
- **Image Changes**: ~30 seconds (rebuilds changed component images)
- **Config Changes**: ~10-15 seconds (Helm redeploy)
- **Cert Renewal**: Automatic, no downtime (every 60 days)
